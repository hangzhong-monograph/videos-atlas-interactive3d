
# Interactive 3D Models

This directory is reserved for interactive 3D scientific
reconstructions associated with the research project:

**Spatial Interfaces of Innate Immunity**

## Planned Content

- Macrophage–infected cell interface reconstructions
- Correlative confocal and FIB-SEM 3D models
- Cellular membrane and organelle segmentations
- Complement-associated erythrocyte membrane structures

## Supported Formats

- GLB / glTF — interactive 3D models for web viewing
- OBJ / STL — surface mesh reconstructions

## Data Availability

The 3D models are currently being prepared.

No unpublished research datasets or restricted
reconstructions are publicly distributed through
this directory at this stage.

Scientific models will be added following verification
of the applicable data-sharing permissions.
